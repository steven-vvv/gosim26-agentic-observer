# 10-07 榜单与上游监控（board-watch）

## 用法

等待间隙交替运行（工作目录 `/home/steven/code/GOSIM26`，我们队名 `CCB`）：

```
uv run python -m v4.evaluation.upstream_watch            # git fetch 上游，列 d293dea..origin/main 触及 challenge/、规则/文档/决赛的提交与引擎 diff 统计；--diff 打印引擎 diff
uv run python -m v4.evaluation.board_watch --diff        # 抓取并保存快照，与上一快照对比（分数变化、新队、名次升降），再打印摘要
uv run python -m v4.evaluation.board_watch --diff --quiet   # 只看变化
uv run python -m v4.evaluation.board_watch --from v4/results/board/<时间戳> --threat   # 离线读快照，附威胁启发式
```

- 阶段 slug 是 `online`（北京时间 10-05 00:00 至 10-07 23:59:59，UTC `ends_at` = 10-07T15:59:59）。A–D 与各卡走 `observer_card_board`，超级榜与 A1–D1 各卡走 `observer_super_board`（卡 slug 为 `v4-a1-v5` 等，从 RPC 返回的 `extra_cards` 自动取）。另有 `observer_super_board_old`（超级榜旧，冻结快照）未接入。
- 快照原始行存 `v4/results/board/<UTC时间戳>/*.json`（overall、v4-a…d、super、v4-a1-v5…d1-v5、_meta），不含 key；匿名 key 只在进程内取用，不打印不落盘。
- 上游检查只 `git fetch`，内容读 `origin/main`，不动克隆的 HEAD。
