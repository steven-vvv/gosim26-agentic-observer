## 1. 时长-字段联合目标函数是否错配

### 代码
- 优先级与科学增益：`v4/agent/observer4/planning.py` 581–583（`science_cap`）、585（`_science_exponents`，265–280）、
  675–679（`science = w·max(0, science_value(reach) − science_value(estimate))`）。
- 锚点内逐时长增益：790–803（`factors = durations × rate`，`science_value(factors) − estimate_value`），
  809–819（+ 必观测奖励 + 请求 + 均匀度，再乘紧迫度/落下加成/地形），832–844 `fiber_totals` 后
  `merit = total / (durations + overhead)`。
- `science_value`：174–190；`fiber_totals`：78–148（每格取最大增益目标，再按格求和）；`_durations`：1065–1077
  （配置时长网格 ∪ 每目标 `阈值/rate` 取整 30 s）。
- 视野衰减：`_science_exponents` 让指数在"今晚之后剩余公开可见时数 < science_horizon_hours(60)"时线性降到 1。

### 数值证据
光纤时间（本次重算，24 卡/类）：

| 类 | idle | superseded | overexposed | partial_final | useful |
|---|---|---|---|---|---|
| a | 16.5 % | 15.8 % | 13.3 % | 25.0 % | 29.4 % |
| b | 53.0 % | 8.9 % | 7.4 % | 14.3 % | 16.4 % |
| c | 1.9 % | 13.4 % | 11.7 % | 33.3 % | 39.7 % |

1. **overexposed 一半出在 >1800 s 的长曝光**（a 50 %、c 35 %），按类别集中在亮目标：a 类 Star 过曝占其光纤时间 65 %、
   BGS 45 %、ELG 28 %、QSO 19 %。这是同场亮暗混合、曝光时长按暗目标定的直接结果。
2. **同格替代检验**（c1.py，每卡 150 次曝光抽样，按该次曝光实测质量校准）：过曝的光纤里，同一格内存在"更需要时间、
   未完成"的替代目标的，a 35 %、c 63 %；但其中按当前 f^1.5 估值替代目标本来就更低的 a 72 %、c 67 %，
   改成线性估值后仍更低的 a 55 %、c 49 %。即**线性化最多改变过曝时间的 a ≈ 6 %、c ≈ 11 %**（约占总光纤时间 0.8 %/0.9 %）。
3. **partial_final 里"同格有能在本次时长内做满的替代"** a 33 %、c 60 %，但被选中的多是权重高的 QSO/LRG（部分 0.7×1.7
   仍大于 BGS 做满 0.45），这是权重驱动、与凸化无关。
4. 时长选择的数学：单目标在饱和前 `f^1.5/d ∝ d^0.5` 随时长单调增，凸化让规划器倾向"把目标拍满"；线性 `f/d` 对时长中性，
   一旦同场有目标饱和就偏向短曝光 → 更多部分曝光与重拍。也就是说凸化是**抑制**重拍的装置，不是过曝的原因。
   历史扫描（指数 1.2 / 1.25 / 1.35 / 1.65 / 2.0）两侧都差或持平（c 上 2.0 −715、1.2 −267；b 上 1.65 +58 [−2,+120] n=8），
   与此一致。
5. **事后的"等效凸性"**（s2.py）：把每次刷新纪录的部分曝光在季内被后来者取代的概率 p(f, t) 拟合成 `f(1−p) ≈ f^γ`，
   γ 按季节六分段：a 3.1/2.6/2.45/2.35/1.85/1.15，b 3.3/2.5/1.9/1.7/1.5/1.2，c 2.95/2.6/2.35/2.0/1.5/1.1。
   这是策略的内生结果（规划器知道以后还能回来），不能直接拿来设指数（指数 2.0 已证明在 c 上大亏），但它说明
   **凸性该在季末最后 1/3 左右开始下降**；当前视野 60 h 只在最后约 1/6 才起作用（a/c 季中剩余可见时数中位 290–460 h，
   到 0.92 季节位置才有 44–49 % 目标低于 60 h）。b 上 hz240 +105 与此吻合。

### 结论与可测替代
- 凸化**没有系统性造成** overexposed/partial_final；二者是共享时长与权重结构的损失，线性化最多回收约 1 % 光纤时间。
- 真正的错配在**重拍的估值**：e>0 时 `f^1.5 − e^1.5` 比真实增量 `f − e` 高（e=0.5→f=1：0.646 对 0.5，高 29 %），
  而实测重拍的每光纤秒产分只有首拍的一半（a 0.30 对 0.59、b 0.29 对 0.75、c 0.46 对 0.78 分/千光纤秒，c2.py）。
  可测替代（#3）：`gain = w·(f − e)·f^(γ−1)`（e=0 时与现状逐位相同，e→1 时趋于 0）。同格近视检验：重拍光纤时间里
  a 3.1 %、b 3.1 %、c 6.9 % 会改选同格未观测目标，每次 +0.12–0.15 分，按全季曝光数放大为近视上界 +66/+83/+94 分/卡；
  场选择层面的效应没计入，长期效应可能抵消一部分。**预期方向：小正，c 最大；置信度低。**
- "分段线性 + 饱和惩罚"（`w·min(f,1) − λ·max(0, r·d − 1)`）预期方向为**负**：它让时长选择对单目标中性，会缩短曝光、
  增加部分曝光与重拍（与指数 1.2 的 −110/−267 同向），不建议测。
- 视野：b 用 240 h（#2）；a/c 维持 60（hz240 +21 不显著、hz30 −25）。

## 3. superseded 浪费（a 15.8 %、c 13.4 %）

### 代码
- 估计更新：`v4/agent/observer4/state.py` 32–80（`feedback` 每次曝光结果回来立即更新 `factor_lower/estimate/best_score`，
  按程序档匹配推断倍率），`_apply` 76–80 取最大。
- 均匀度：`state.py` 119–129 `uniformity_gain`，planning.py 753 乘 `uniformity_weight`，815 仅对 `factor_lower < 0.5 且 safe` 的目标加。
- 重拍估值：planning.py 677–679、797–803（`science_value(f) − estimate_value`）。

### 证据
1. **不是 estimate 滞后**：被取代的曝光与取代者间隔：同夜 1.7 %（a）/1.4 %（b）/2.7 %（c），1–7 夜 13–16 %，8–30 夜 29–32 %，
   >30 夜 51–54 %。已做满（raw ≥ 1）却又被重拍取代的只有 2.8 %/1.9 %/0.4 %。
2. **不是均匀度项**：季 1/3 处每目标均匀度增益中位 0.006（a）/0.003（b）/0.007（c），p90 0.016–0.028，相对科学增益（0.3–1.7）可忽略。
3. **是什么**：97–99 % 的被取代曝光发生在取代者之前，且 71–74 % 的取代者把目标做满了。按链条拆（s3.py，占已指派光纤时间）：
   首拍部分→后来被取代 a 12.7 %、b 12.1 %、c 10.6 %；重拍部分→再被取代 a 3.2 %、b 3.3 %、c 1.2 %。
   被取代的首拍因子分布：<0.25 22 %、0.25–0.5 25 %、0.5–0.75 33 %、0.75–0.95 15 %。
   季初占一半（a 51 %、b 65 %、c 49 %），28 %（a）/27 %（b）/20 %（c）落在"本次曝光新完成了必观测目标"的曝光里（必观测奖励 200 驱动的短曝光把同场科学目标只拍一部分）。
4. 被取代的光纤时间多半并非望远镜时间的浪费——那根光纤在那次曝光里没有更好的目标（a 每格平均只有 1.9 个未完成可见替代，
   c 5.8 个）。真正的代价是**重拍本身**：重拍占已指派时间 a 37.6 %、b 44.5 %、c 24.3 %，每光纤秒产分只有首拍的 38–60 %。

### 抑制方案（可测）
- **#3 重拍按增量计价**（见 §1）：直接针对"重拍被高估 ~29 %"。实施：新文件 `observer4/valuation.py` 提供
  `revisit_gain(factors, estimate, exponent, cap)`，planning.py 两处 `science_value(...) − estimate_value` 改调它，加开关
  `policy.revisit_increment`（默认 false，保证默认动作哈希不变）。planning.py 余量只有 562 字符，替换时要等量删减。
- 必观测短曝光（28 %）不建议再动：10-05 已测奖励 100/60/安全因子 0.6 全负。
- 不建议用 "首拍部分折价"（=季初加大指数），指数 2.0 已在 c 上 −715。

## 4. 暗目标欠曝与 science_cap_quality

### 代码
planning.py 581–583：`typical = science_cap_quality`，`cap = clip(flux·typical·max_exp/zp, 0.05, 1)`；`science_value` 174–190：
f < cap 时取 `cap·(f/cap)^γ`，f ≥ cap 取 f。

### 证据
1. **影响范围**：cap < 1 当且仅当 `flux < zp/(typical·3600)`。typical=0.8 时 a/c（zp 450）为 flux < 0.156，约 40 % 的 QSO
   （a、c 各约 1,700 个/卡，占目标 6 %）；b（zp 800）阈值 0.278，几乎不影响任何类；d 不相关。
2. **方向**：对 cap<1 的目标，部分曝光的估值乘以 `cap^(1−γ)`（γ=1.5、cap=0.5 时 ×1.41），即**提高暗 QSO 的优先级**并让它们更接近线性计价。
3. **但暗 QSO 是每光纤秒产分最低的一类**（a，质量中位 0.73）：faint QSO（flux≈0.12）1.7×0.12×0.73/450 = 3.3e−4 分/秒；
   中位 QSO 5.0e−4；LRG 5.7e−4；ELG 8.9e−4；BGS 9.1e−4（494 s 内）；Star 1.95e−3（155 s 内）。在 1,800 s 的场里一根光纤给暗 QSO
