# 2026-10-08 季末收尾（末态部分）实验：诊断上界与 completion_bonus 的否决

分支 `finish`（从 `cand-ov` 切出）。诊断数据：包 05f4 与 de30 的 trial-a / trial-c
（逐卡 12 万条曝光），脚本与原始输出在 `/tmp/finish/diag*.py`（只读，未入库）。

## 1. 诊断上界（决定投入的量级）

| 口径 | trial-a | trial-c |
|---|---|---|
| 季夜数 | 123 | 121 |
| 末态部分目标（best factor < 1） | 10,613 | 10,636 |
| 其中一次 3600 s 曝光可拍满 | 9,148 | 10,179 |
| 价值（w·缺口，未乘程序倍率） | 2,723.6 | 2,850.7 |
| **只算"最后一个可拍满的夜仍未使用"** | **496 个 / 35.3 分** | **675 个 / 36.5 分** |
| 部分目标拍满所需单次时长（中位） | 1,727 s | 1,224 s |
| 实际最后一次曝光时长（中位） | 1,170 s | 900 s |
| 平均曝光次数（可拍满的那批） | 1.12 | 1.16 |

**季末"最后一次可见机会"这个口径的上界只有约 35 分/卡，低于 100 分门槛。**
缺口不在"季末最后没抓住"，而在**整季只给一次短曝光**：可拍满的部分目标平均只被观测
1.12 次，中位时长只有所需时长的 68%。缺口按因子桶集中在 0.2–0.6（a：2,152 / 4,160 分）。

时长决策的口径（`diag4`，3,102 次曝光）：曝光时长 / 场内平均所需时长中位 **1.073**，
而 / 场内最慢目标所需时长中位 **900 / 3,199**；一次曝光已饱和的指派目标占比中位 **0.500**。
即**时长由场内平均（多为亮目标）决定，暗目标只拿到需求的一小部分**。

cap 校验（planning 的 `science_cap`，lean 档 `science_cap_quality` 0.6）：部分目标中位 cap
QSO 0.798（a）/0.808（c），其余类 1.0；中位 best factor QSO 0.540 / 0.617。**QSO 远未触顶**，
不存在"延长到 cap 之上无意义"的解释。

## 2. 可测机制：`completion_bonus`（默认关）

`policy.completion_bonus`（0–500，默认 0）与 `policy.completion_nights`（1–200，默认 30）：
一次候选时长若能把**已部分观测**的目标拍满，且该目标的剩余可见夜数少于 `completion_nights`，
就按接近度加权追加奖励。只对"本就可以拍满"的目标加码，不浪费光纤时间在拍不满的目标上。
开关默认关，`completion_bonus = 0` 时动作序列与 `cand-ov` **逐位一致**
（trial-a 本地：`action_sha256 = ff62e2985bfb…` 与 cand-ov 工作树完全相同，total 26616.837369 一致）。

## 3. 筛查结果（scr-ac32，a 16 + c 16，逐卡配对 default）

| 变体 | Δ均值 | 95% CI | 胜/负 | CPU 比 | 末态部分占比 a | c | 未满目标 a | c |
|---|---|---|---|---|---|---|---|---|
| cb100（bonus 100，30 夜） | **−2132.3** | [−2214.5, −2050.0] | 0/32 | 1.01x | 31.1→20.5% | 35.1→20.2% | 11482→7650 | 11657→6112 |
| cb250（bonus 250，30 夜） | **−2154.3** | [−2232.6, −2078.7] | 0/32 | 1.00x | 31.1→20.4% | 35.1→20.2% | 11482→7627 | 11657→6088 |
| cb250n90（bonus 250，90 夜） | **−4284.7** | [−4642.6, −3946.0] | 0/32 | 0.95x | 31.1→11.5% | 35.1→8.8% | 11482→4191 | 11657→2526 |

**机制达到了设计目标**（末态部分占比 31% → 20%，未满目标 −3,800/卡），**但总分大幅下降**。
原因：为了把暗目标拍满而延长的那些曝光，挤掉了本可以铺更多曝光的机会；产分率下降的代价
远超"把部分目标补到 1"的收益。分母（望远镜时间）是满的，补满一个目标要多花的秒数换来的
增量，低于它挤掉的曝光在同一秒数里能产出的分。三种设置同向且 CI 完全在负区间，
**比 10-07 的 e20/e35/e50 无条件延长（−2628/−612/−263）更清楚地否定了这条方向**。

## 4. 结论

- 季末收尾专用机制的上界 **≈ 35 分/卡**（"最后一个机会"口径），**低于 100 分门槛 → 不做**。
- 普遍欠曝的 2,723 / 2,851 分上界**是不挤占的假想值**：实测把曝光拉长以补满暗目标，
  净收益为 **−2,100 至 −4,300 分/卡**。生产函数在季中测试下就是"短曝光多铺"更优。
- `completion_bonus` 保留为默认关的旋钮（逐位一致已核），备后续在**结构不同**的卡
  （例如 d 卡时间充裕、b 卡时间饱和）上单独验证；**a/c 上不再投入**。

## 5. d 卡（big-d24v）的追查：无事可做

按协调者要求先用同一诊断查 d，**结论是杠杆无事可做，未投入池实验**。数据是 de30 的 trial-d
（365 夜、100 光纤、3 万目标）：

| 指标 | trial-d |
|---|---|
| 被观测目标 | **30,000 / 30,000（100 %）** |
| 末态部分目标（best factor < 1） | **1,015（3.4 %）** |
| 平均 best factor | **0.9923** |
| 缺口总额（w·缺口） | **390.1 分**，其中 QSO 386.6（951 个，均因子 0.761） |
| 部分目标中"拍满所需 > 3600 s" | **624 个**（物理上拍不满） |
| 部分目标中"一次 3600 s 曝光可拍满" | **391 个** |
| 这些可拍满目标的价值 | **67.4 分** |
| 平均曝光次数（可拍满的那批） | 3.2 |
| 观测窗占用（曝光时长 / 可观测窗口） | 87.2 %（2,514 h / 2,884 h） |
| 实际曝光时长中位 / p95 | 1,620 s / 3,600 s（15 % 已达上限） |

三类失分结构都不支持这条机制：

1. **可拍满的目标只有 391 个，价值上界 67.4 分**（未乘程序倍率），而 d 的基线总分 32,974.8 ——
   上界 0.20 %，**低于 100 分门槛**。而且这是**不挤占**的上界；d 的占用率 87.2 % 意味着
   延长曝光仍会挤掉别的曝光，净收益只会更低。
2. **缺口集中在物理上拍不满的目标**：1,015 个部分目标里 624 个（61 %）所需单次时长 > 3,600 s，
   任何时长决策都救不回来。可拍满的 391 个里 313 个所需时长在 2,400–3,600 s 之间——
   它们**已经拿到了接近上限的时长**（15 % 的曝光已达 3,600 s）。
3. **部分目标是"重拍后仍未拍满"**：727 个（72 %）已被观测 ≥ 3 次，占 283.8 / 390.1 分；
   只观测 1 次的仅 44 个。**这与 a/c 的形状相反**（a/c 是"只碰一次、时长不够"），
   所以在 a/c 上成立的机制前提在 d 上根本不成立。d 的瓶颈是**目标本身拍不满**（暗 QSO 需
   > 3,600 s），不是"没给足机会"。

因此 `completion_bonus` 在 d 上既无空间也无风险收益：它只会把本已接近上限的曝光再拉长，
挤掉产出，方向与 a/c 的负结果同型。**未运行 big-d24v 筛查**；d 保持现状（基线 32,974.8，
我们四卡最高分，不为一个上界 67.4 分的杠杆承担回归风险）。
