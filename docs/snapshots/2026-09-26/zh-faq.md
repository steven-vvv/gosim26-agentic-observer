常见问题

# 报名前的问题

我编程基础一般，最少要做什么？

下载入门包，双击 run\_baseline，然后只改 agent/my\_strategy.py 里的一个函数：它收到「现在能观测的候选」（已排好序），返回要观测的那个或 None 等待。改完再双击 run\_baseline，把生成的 run\_output/decisions.csv 拖到「提交」页即可。macOS 自带的 Python 就够用，Windows 从 python.org 装 Python 3.12。

需要天文背景吗？

不需要。智能体收到的是 JSON 快照：当前时隙天气、带高度、airmass、月光因子、有效条件与 tile\_science\_value 的候选天区、迄今发布的预报与请求，以及进度。文档解释了会出现的少数术语，scoring\_preview.py 也已经能把快照变成候选排序。

可以个人参赛吗？

可以。创建人数上限为 1 的队伍即可。队伍最多 3 人。

可以用什么语言？

实现语言不限，在本地运行后提交 decisions.csv，或提交完整项目。

可以使用大模型或商业 API 吗？

可以。智能体在你自己的电脑上运行，决策时也可以调用模型，用自己的密钥或控制台里领的赞助兑换码。180 晚场景约 8,000 次决策，每次都调用模型会很慢；把显而易见的等待交给确定性代码。

什么是全局时钟？

每个场景公布 global\_wallclock\_seconds（参考场景 7200 秒，短场景更少）。它在 initialize 消息后开始并覆盖全部决策——包括快照序列化、你的思考时间与解析。没有单次决策限制。到期时进程被停止，已提交动作照常评分，并适用未完成 必做天区、可选天区缺额与到期请求的终局惩罚。

可以下载哪些场景数据？

当前场景的天气、预报和事件公开，可使用 score\_decisions.py 复现成绩。

可以提交多少次？

每队每天可以提交 50 次 CSV，每个场景分别取该队最高分排名；完整项目每天 5 次，单独排名。

排行榜分数就是最终成绩吗？

练习赛榜单用于练习，不决定奖项。

必须到深圳现场吗？

不需要。比赛在线进行。获奖队伍受邀参加 10 月 17 日 GOSIM 深圳颁奖日，也可以远程领奖。

平台是否免费？

是。报名、数据、入门包与评分均免费。

必须开源吗？

不强制。确认奖项前，主办方可能要求前列队伍提供智能体代码，用它重新生成 decisions.csv 以复现结果。

智能体崩溃或超时会怎样？

未能在 30 秒内初始化、退出或回复无效消息的运行以 agent\_error 或 agent\_initialization\_error 结束。此前提交的动作照常评分并适用终局惩罚，智能体的 stderr 末尾显示在提交页。全局时钟到期时同样只对已提交动作评分（global\_wallclock\_expired）。修复后在每日限额内重新提交即可。

奖金是否含税？

奖金为税前金额。支付细节在颁奖日后与获奖队伍确认。

开发阶段有 API 额度吗？

已注册队伍可在控制台领取赞助商 API 兑换码，每队每个服务商一个，用于在本地运行智能体时调用模型。

其他问题： [hackathon@gosim.org](mailto:hackathon@gosim.org)
